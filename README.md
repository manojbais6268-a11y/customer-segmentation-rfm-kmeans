
# Customer Segmentation Analysis using RFM and K-Means

## Project Overview
This project performs customer segmentation using RFM Analysis and K-Means Clustering to understand customer purchasing behaviour.

## Objectives
- Analyze customer purchasing patterns
- Perform RFM analysis
- Apply K-Means clustering
- Identify meaningful customer segments
- Generate business insights

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Workflow
1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis
4. RFM Analysis
5. Feature Scaling
6. K-Means Clustering
7. Customer Segment Analysis
8. Business Insights

## How to Run
1. Clone this repository.
2. Install the required libraries.
3. Place the dataset in the project folder.
4. Open the notebook in Jupyter Notebook.
5. Run all cells.
